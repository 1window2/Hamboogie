# Hamboogie

디시인사이드 갤러리에서 나눔(뿌리기) 글을 감지하고, 로그인한 계정으로 조건에 맞춰 자동으로 줄을 서는 Windows/macOS 데스크톱 프로그램입니다.

> 개발 초기 단계입니다. 아래는 확정된 설계 요약입니다.

## 동작 흐름

1. 지정한 갤러리의 새 글 목록을 주기적으로 확인합니다.
2. 제목 키워드로 1차 필터링합니다.
3. 통과한 글의 제목과 본문 텍스트를 LLM이 분석해 나눔 글인지, 어떻게 줄을 서야 하는지 판단합니다.
4. 판단 결과에 따라 대기 중인 계정으로 댓글을 달거나, 넘어가거나, Discord 웹훅으로 알립니다.

## 갤러리 설정

- 갤러리 ID(URL상의 이름, 예: `gf2`)와 마이너 갤러리 여부를 지정합니다.
- `+` 버튼으로 여러 갤러리를 동시에 감시할 수 있고, 갤러리마다 아래 항목을 따로 설정합니다.
  - **감시 간격:** 기본 5분, 최소 10초에서 최대 1시간
  - **나눔 종류:** "음식만" 또는 "모두" 중 하나
  - **대기 계정:** 등록된 계정 중 하나 이상, 우선순위 순서 지정
  - **줄 서기 지연:** 나눔 글을 감지한 뒤 댓글을 달기까지 기다릴 시간. 기본 0초(즉시)
- **제목 키워드:** 최대 30개까지 설정합니다. 비워두면 모든 새 글을 LLM에 보내므로, LLM 토큰이 매우 빠르게 소모된다는 강한 경고를 표시합니다.

## 계정

- 여러 계정을 등록할 수 있습니다.
- 나눔 글 하나에는 프로그램 전체에서 **댓글 하나만** 답니다.
- 조건에 맞는 가장 높은 우선순위의 계정 하나가 줄을 섭니다. 예를 들어 "고닉만" 조건이면 고닉 계정이 섭니다. 실패하면 다음 순위 계정이 시도합니다.
- 고정닉/반고정닉 여부는 API로 확인합니다. 확인할 수 없으면 계정 설정에서 직접 지정합니다.
- 계정 비밀번호와 API 키는 OS 보안 저장소에 암호화해 보관합니다.

## 줄 서기 판단 (LLM)

- 분석 대상은 제목과 본문 텍스트뿐이며, 이미지는 분석하지 않습니다.
- 본문 없이 제목만 "~~분까지"인 글도 나눔 글로 판단합니다.
- LLM은 정해진 선택지 중 하나만 고를 수 있습니다.
  - **텍스트 댓글:** 기본값 "줄". 글에서 특정 문구를 요구하면 그 문구를 씁니다.
  - **디시콘 댓글:** 해당 계정이 보유한 디시콘 중 하나만 쓸 수 있습니다.
  - **넘어가기:** 나눔 글이 아닌 경우, 나눔 종류가 맞지 않는 경우, 계정 조건(고닉 전용 등)상 설 수 없는 경우, 마감 시각이 지난 경우
  - **알림:** 조건을 이해할 수 없거나 자동으로 처리할 수 없는 경우. 개인정보나 외부 링크를 요구하는 경우도 여기에 해당합니다.
- "N시부터" 조건은 그 시각까지 기다렸다가 줄을 섭니다.
- 지원하는 LLM은 Gemini(기본), ChatGPT, Claude이며, 사용자가 직접 API 키를 입력합니다.

## 알림과 로그

- 줄 서기 성공은 프로그램 내부 로그에만 남깁니다.
- 실패하거나 판단할 수 없는 경우에만 Discord 웹훅으로 알립니다.

## 기술 구성

- Electron + TypeScript
- 디시인사이드 통신: [dcinside.js](https://github.com/green1052/dcinside.js) (GPL-3.0)
- UI 언어: 한국어

## 개발

Node.js 22.12 이상이 필요합니다.

```sh
npm install
npm run dev          # 개발 모드로 실행
npm test             # 단위 테스트
npm run typecheck    # 타입 검사
npm run dist:win     # Windows 설치 파일 빌드 (release/)
npm run login-test   # dcinside.js 로그인 테스트 (아이디/비밀번호를 직접 입력)
```

Windows 설치 파일은 GitHub Actions에서도 빌드되어 실행 결과의 아티팩트로 올라갑니다.

### 구조

| 경로 | 내용 |
|---|---|
| `src/shared` | 설정 타입, 기본값, 설정 검증 |
| `src/main/dc` | dcinside.js 래퍼: 계정 로그인, 디시콘, 본문 텍스트 변환 |
| `src/main/llm` | LLM 판단 스키마, 프롬프트, Gemini/ChatGPT/Claude 호출 |
| `src/main/pipeline` | 감시 엔진, 키워드 필터, 줄 서기 계획 |
| `src/main/notify` | Discord 웹훅 |
| `src/main/store.ts` | 설정 파일, 암호화된 비밀 정보, 처리한 글 기록 |
| `src/preload` | 화면과 메인 프로세스를 잇는 API |
| `src/renderer` | React 화면 |
